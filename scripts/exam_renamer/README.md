# Gestor de Exámenes PDF (exam_renamer.py)

Una herramienta gráfica en Python (Tkinter) para renombrar, visualizar y dividir exámenes en formato PDF.

## Instalación

Instala las dependencias usando el archivo `requirements.txt` dentro de esta carpeta:

```bash
pip install -r scripts/exam_renamer/requirements.txt
```

## Uso

Ejecuta el script desde la raíz del repositorio:

```bash
python scripts/exam_renamer/exam_renamer.py
```
